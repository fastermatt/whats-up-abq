# IG Post Examples — 3 Different Styles

Three fully-specified Instagram post examples in **three distinct visual/voice directions** so you can pick which style the @abqunplugged account should lead with.

All three are built around the **same event** (Buckethead at El Rey Theater tonight) so you can compare apples-to-apples: same subject, different treatment.

| File | Style | Voice | Visual |
|------|-------|-------|--------|
| `01-poster-style.md` | **Typographic poster** — text does all the heavy lifting | Confident · deadpan · one-liner | Full-bleed image with large Epilogue text overlay |
| `02-photo-forward.md` | **Documentary photo** — let the event speak | Minimal · observational · quiet | Gorgeous real photo, captions in the caption, no text on image |
| `03-editorial-carousel.md` | **Multi-slide editorial** — teach/sell/show | Warm · curated · "I went last year" | 5-slide carousel mixing photo + quote cards + stats |

**What to look for when picking:**

1. **Which one makes you want to tap "save"?** (IG's most-weighted signal)
2. **Which one represents who you want @abqunplugged to be?**
3. **Which one can you realistically produce 3–5x per week?** A stunning carousel nobody has time to make = no posts.

After you pick a direction, I'll rewrite the full 10-post queue in that style.

The background research agent is still running — it's pulling patterns from @secretnyc, @dothebay, @infatuation, @eater, etc. When it completes, the file `../00-strategy-and-review.md` will have the benchmark data.
